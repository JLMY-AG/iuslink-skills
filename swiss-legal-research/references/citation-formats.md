# Citation Formats

## Federal Court (BGE) citations
- Format: BGE <volume> <part> <page>
- Example: BGE 140 III 86

## Cantonal Court citations
- Format: <CantonLetter>_<DocketNumber>/<Year>
- Example: 6B_123/2022

## Legislative references (SR numbers)
- Format: SR <number>
- Example: SR 220

When a citation is ambiguous, first run search_entscheidsuche with the raw string to surface possible matches.
